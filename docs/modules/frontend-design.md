# 前端页面与接口协作

Vue3 / TypeScript沿用TASK-001已有构建工具。界面优先中文，技术key保留原名并提供中文解释。业务用户页面不展示Outbox、leaseToken等实现细节。

| 页面 | 核心内容 | TASK |
| --- | --- | --- |
| Agent/数据集/方案 | 列表、版本详情、草稿编辑、发布/归档 | 003 |
| 实验创建与列表 | 模式、固定版本、对象、重复次数、预算；草稿检查 | 004 |
| 离线导入 | 上传、类型、样本绑定、错误行、恢复进度、缺失槽位 | 005 |
| Run详情 | 输入/期望/输出、Attempt选择、事件、算子与证据 | 006/007 |
| 算子结果 | 结论、有效分数、缺失原因、Judge标记 | 007/008 |
| 标注工作台 | 待领、已领、提交、审核、历史与冲突刷新 | 009 |
| 实验报告 | 分母、配对变化、失败清单、成本、门禁 | 010 |

发布后隐藏编辑动作并展示复制新版本入口，服务端仍必须校验。在线/离线两个入口共用Run详情组件。技术状态与任务结果分列：如“流程完成 / 任务失败”；算子技术异常与质量FAIL分开颜色和解释。

轮询仅在QUEUED/RUNNING等活动状态启用，默认2秒，失败退避，页面离开取消；终态停止。暂无WebSocket/SSE依赖。文件上传需展示实际已知进度；后台导入扫描未完成前只展示已处理行数。

所有页面覆盖loading、empty、error、permission、部分数据、未知成本和证据缺失状态。API错误提示保留requestId供排障，不能展示服务器堆栈。对于409给出刷新并保留当前输入；不要自动重复状态动作。

将secretRef显示为引用名，密钥输入交给环境配置；界面不持久化明文密钥到localStorage。文本日志与Markdown内容按不可信数据处理，禁用原始HTML与危险URL。列表支持键盘操作和明确表单标签。

TypeScript类型由实际OpenAPI生成或保持CI对照，不能直接复用数据库Entity字段。前端Mock只用于开发测试，正式演示必须切换真实Java API并标注哪些Runner仍为Mock。
